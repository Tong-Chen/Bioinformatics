# Applied Bioinformatics 实用生物信息学技术

课程中文名称：实用生物信息技术

课程英文名称：Applied Bioinformatics
课程编号：Z02211

一、课程概述

本课程旨在介绍在生物信息学中最常用的编程语言（Shell, R和Python），讲解常用的生物信息学分析软件包的基本原理和使用方法，分享组学前沿技术(如基因组、转录组、泛基因组、扩增子、宏基因组等)，希望学生在掌握本课程的知识和技能后，能够自己解决正在进行或即将开始的研究课题中的实际问题，同时邀请行业专家分析项目经验、AI科研赋能、论文图片设计与打磨，提高同行科研效率，加速科学发现和成果产出。本课程不是以课堂讲授为主的理论课，而是一门将老师讲解、上机操作和项目制学习相结合的课程。除课堂教学外，还将研究领域相似的学生划分成不同的小组，整个课程期间小组内同学互相学习和讨论、完成必要的课外练习。

三、先修课程

分子生物学、遗传学、基因组学

四、课程目标

通过本课程学习，除了掌握常用编程语言的核心用法外，学生们还将掌握连接远程服务器，记录并备份编程语言，对二、三代高通量测序数据进行比对、基因差异表达分析、扩增子、宏基因组数据分析，关联图谱分析，群体遗传结构分析，基因功能区域划分、机器学习原理与应用、大语言模型/AI智能体在科研中的应用等。课程的最后，小组内同学在领域内选择已经发表的有关处理大数据的文章，讨论基于已经发表的数据可以设计一些新的分析方法，解决一些新的问题，最后以PPT展示出来。对于优秀的成果，可以后期组织学生撰写论文。

五、适用对象

适用于各专业的博士研究生或硕士研究生

六、授课方式

本课程采用课堂讲授和上机实习同步进行的方式，必须具备较好网络环境和PPT放映系统。
